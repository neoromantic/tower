# Game settings and concepts

Concepts belong in separate visible discussion threads and research documents. Only implemented experiments and alternatives belong in the game's Settings, with live controls that preserve the ongoing tower and session. Keep engineering documentation and provenance out of gameplay flows.

Current-engine display/UI modernization, four complete selectable gameplay styles, original splash art, mobile PWA/local progress and production deployment are approved. Three.js is approved as the default browser renderer. Full core extraction and native iOS work require their own discussion decisions.

Never use Vercel AI Gateway for anything except Jev. Do not generate new images; use existing source assets. Preserve honest historical provenance and costs for existing assets.
