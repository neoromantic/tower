Современный экран / концепция

Сохранить C/SDL2 и симуляцию. Развести плотность пикселей, масштаб интерфейса и zoom мира: Retina делает текст чётче, широкий экран показывает больше башни, панели сохраняют удобный размер. Сейчас canvas — 960×720, zoom ещё не реализован. Предлагаемый порядок: согласовать буфер и координаты → отделить viewport мира → постепенно вынести браузерные панели в DOM. Изменение темпа симуляции и новые механики сюда не входят. Реализация не согласована.

Новый рендерер / концепция

При реальном намерении перейти к объёму предлагается THREE.js с ортографической камерой: сначала плоские помещения, позже геометрия в той же сцене. Для чистого 2D PixiJS ближе к нынешним спрайтам. В обоих случаях остаётся C/WASM-симуляция и появляется явная граница snapshots → view / commands → core. Уже сейчас браузер использует ускоренный SDL renderer; обещаний прироста FPS без измерений нет. Здесь нет работающего альтернативного движка; миграция не согласована.

Игровое ядро / концепция

Выделить всю неинтерфейсную логику возможно, сохранив C. game.c, people.c и tower.c уже работают без SDL, но в main.c остаются правила строительства, цены и последствия действий. Дополнительные связи — глобальное состояние, общий rand(), звук/web hooks и ABI-зависимые saves. Предлагается небольшой контракт: команды, tick, read-only snapshots, события, save bytes и версия content/rules. Переносить правила по одному через старый UI, затем подключать новый. Это проект границы, реализация не согласована.
